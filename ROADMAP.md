# Roadmap & Product Status

## Current Release Status

Already shipped in the current public package:

- [x] Day, week, month, and planning views
- [x] Drag and drop, resize, create, delete, and show-more interactions
- [x] Headless styling modes: full CSS, structure-only CSS, theme-only CSS, theme overlay, and `unstyled`
- [x] English, French, and German locale helpers
- [x] Curated root exports for the npm package
- [x] Framework-agnostic packaging for React consumers
- [x] Reference integrations for Vite and Next.js App Router
- [x] Package-level publication validation for the published npm surface
- [x] Removal of non-implemented public APIs for resources and virtualization from the current contract
- [x] Accessibility hardening for screen readers and keyboard date navigation on shipped views
- [x] Performance hardening on current time-calculation and week-grouping hot paths
